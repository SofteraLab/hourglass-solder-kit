# Soldering

![Assembly order](../assets/images/en/assembly.png)

- Start with small SMD, then **ATmega328P** (pin 1).  
- **USB-C** — flush to the edge; all pins and tabs soldered.  
- Matrix modules — match silk orientation; check daisy-chain.  
- **MPU-6050** — seat fully on the header.  
- **LiPo** — red to **BAT+**, black to **BAT−** only.  
- Flash demo with **ICSP** (Upload Using Programmer).
