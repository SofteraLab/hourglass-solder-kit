# Старт

![Порядок збірки](./assets/images/uk/assembly.png)

## Порядок

1. SMD-пасиви + **ATmega328P** (+ кварц)  
2. Ланцюг зарядки, **USB-C**, LED **CHARGE**  
3. Бузер, On/Off, Reset, кнопки SET  
4. Обидві LED-матриці  
5. Вставте **MPU-6050**  
6. Підключіть **LiPo** (**BAT+ / BAT−**)  
7. Прошийте [`firmware/HG_Hourglass`](../firmware/HG_Hourglass/)  
8. **On** → пісок → **переверніть** плату  

![Переворот](./assets/images/uk/flip.png)

## Живлення

- **USB-C** — зарядка  
- **LiPo** — автономна робота  
- **On/Off** — головний вимикач
