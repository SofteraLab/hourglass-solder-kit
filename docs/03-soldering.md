# Пайка

![Порядок збірки](./assets/images/uk/assembly.png)

- Починайте з дрібного SMD, далі **ATmega328P** (pin 1).  
- **USB-C** — рівно по краю; усі контакти й вушка.  
- Матриці — орієнтація за шовкографією; ланцюг daisy-chain.  
- **MPU-6050** — щільно в роз’єм.  
- **LiPo** — червоний на **BAT+**, чорний на **BAT−**.  
- Прошивайте демо через **ICSP** (Upload Using Programmer).
